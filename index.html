How to install

It takes about a minute.

Install on macOS

Uses the .dmg download.

  1. Open the downloaded .dmg file. It's usually in your Downloads folder.
  2. In the window that appears, drag the CadYam icon onto the Applications folder.
  3. Open Applications and double-click CadYam.
  4. The first time, macOS asks whether you want to open an app downloaded from the internet. Click Open.
  5. Eject the CadYam disk image in Finder's sidebar. You can delete the .dmg file now.

Tip: to keep CadYam in your Dock, right-click its Dock icon while it's running and choose Options → Keep in Dock.

Install on Windows

Uses the .exe installer.

  1. Run the downloaded installer. If your browser asks whether to keep the file, choose Keep.
  2. Windows may show a blue "Windows protected your PC" screen. Click More info, then Run anyway.
  3. Follow the installer. It installs for your user account only, so it doesn't ask for an administrator password.
  4. Start CadYam from the Start menu.

Why the warning? The Windows installer isn't code-signed yet, so SmartScreen doesn't recognize it. To check that your download is the real one, compare its checksum with the list under Verify your download.

Debian, Ubuntu and relatives

Uses the .deb package.

  1. Open a terminal in the folder you downloaded it to.
  2. Install it with apt, which also installs anything it depends on: 
    sudo apt install ./cadyam_VERSION_amd64.deb
  3. Start CadYam from your applications menu, or run cadyam.

Any other distribution

Uses the AppImage.

  1. Make the downloaded file executable: 
    chmod +x cadyam_VERSION_x86_64.AppImage
  2. Double-click it, or run it from the terminal: 
    ./cadyam_VERSION_x86_64.AppImage

AppImage won't start? On Ubuntu 22.04 and later, install FUSE 2 first: sudo apt install libfuse2 (on Ubuntu 24.04 it's libfuse2t64).

Verify your download

Each release includes SHA256SUMS.txt, which lists the SHA-256 checksum of every file. To check a file, run the command for your system and compare the result with its line in that list.

macOSshasum -a 256 <file>
WindowsGet-FileHash <file> in PowerShell
Linuxsha256sum <file>

Staying up to date

CadYam checks for a new version once a day. When one is out, it offers Update and restart, and updates itself in place. You only need this page for a first install.

To see what changed in each version, read the release notes.
